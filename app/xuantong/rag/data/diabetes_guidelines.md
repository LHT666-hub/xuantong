# 糖尿病管理指南摘要

## 诊断标准
- 空腹血糖 ≥ 7.0 mmol/L
- 口服葡萄糖耐量试验 2h 血糖 ≥ 11.1 mmol/L
- 随机血糖 ≥ 11.1 mmol/L 伴典型症状
- HbA1c ≥ 6.5%

## 分型
- 1型糖尿病：胰岛β细胞破坏，胰岛素绝对缺乏
- 2型糖尿病：胰岛素抵抗为主伴相对分泌不足
- 妊娠期糖尿病
- 其他特殊类型

## 控制目标
| 指标 | 目标值 |
|------|--------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 非空腹血糖 | < 10.0 mmol/L |
| HbA1c | < 7.0% |
| 血压 | < 130/80 mmHg |
| LDL-C | < 2.6 mmol/L |

## 生活方式管理
- 饮食控制：总热量控制，碳水化合物占 50-60%
- 运动治疗：每周 ≥ 150 分钟中等强度有氧运动
- 体重管理：BMI 目标 < 24
- 自我血糖监测

## 常用降糖药物
- 二甲双胍：一线用药，改善胰岛素敏感性
- 磺脲类：格列美脲、格列齐特（促胰岛素分泌）
- DPP-4 抑制剂：西格列汀、维格列汀
- SGLT2 抑制剂：达格列净、恩格列净
- GLP-1 受体激动剂：利拉鲁肽、司美格鲁肽
- 胰岛素：基础胰岛素 + 餐时胰岛素方案

## 低血糖处理
- 意识清醒：口服 15g 快速碳水化合物（葡萄糖片、果汁）
- 意识障碍：静脉注射 50% 葡萄糖 40-60ml 或肌注胰高血糖素
- 15 分钟后复测血糖，仍低则重复处理

## 并发症筛查
- 眼底检查：每年一次
- 肾功能：尿微量白蛋白/肌酐比值
- 足部检查：每日自检 + 年度专业检查
- 神经病变：10g 尼龙丝试验
- 心血管风险评估
