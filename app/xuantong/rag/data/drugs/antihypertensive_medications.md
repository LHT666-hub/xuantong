# 常用降压药知识（基层）

> 来源：《国家基层高血压防治管理指南（2025 版）》及国家基本药物目录，用药要点整理

## 五大类一线降压药速览
| 类别 | 代表药物 | 常用剂量（口服） | 常见不良反应 |
|------|----------|------------------|--------------|
| CCB 二氢吡啶类 | 氨氯地平 | 2.5-10 mg qd | 踝部水肿、面部潮红、头痛、牙龈增生 |
| CCB 二氢吡啶类 | 硝苯地平控释片 | 30-60 mg qd | 水肿、心悸、潮红 |
| ACEI | 培哚普利 / 依那普利 | 4-8 mg qd / 5-10 mg qd-bid | 干咳、高钾血症、首剂低血压 |
| ARB | 缬沙坦 / 氯沙坦 | 80-160 mg qd / 50-100 mg qd | 高钾血症、头晕（一般无干咳） |
| 利尿剂（噻嗪类） | 氢氯噻嗪 / 吲达帕胺 | 12.5-25 mg qd / 1.25-2.5 mg qd | 低钾、高尿酸、糖脂代谢异常 |
| β 受体阻滞剂 | 美托洛尔缓释片 / 比索洛尔 | 47.5-95 mg qd / 2.5-10 mg qd | 心动过缓、乏力、掩盖低血糖 |

> qd=每日一次，bid=每日两次；剂量应个体化，从小剂量起始。

## 禁忌症要点
- **ACEI/ARB**：双侧肾动脉狭窄、妊娠、血管神经性水肿史、高钾血症；ACEI 与 ARB 不联合
- **CCB（非二氢吡啶类：维拉帕米、地尔硫卓）**：失代偿心衰、严重传导阻滞；短效硝苯地平禁用于急性冠脉综合征
- **利尿剂**：痛风慎用噻嗪类，严重低钾、肾功能不全需评估
- **β 受体阻滞剂**：严重心动过缓（< 50 次/分）、二度以上房室传导阻滞、支气管哮喘、急性心衰失代偿期

## 药物相互作用
- ACEI/ARB + 保钾利尿剂（螺内酯）或补钾剂 → 高钾血症风险↑
- ACEI/ARB + NSAIDs（如布洛芬）→ 肾损害风险↑、降压效果↓
- β 受体阻滞剂 + 非二氢吡啶类 CCB → 心脏传导抑制、心动过缓
- 噻嗪类利尿剂 + 地高辛 → 低钾诱发洋地黄中毒
- CCB（维拉帕米/地尔硫卓）+ 他汀（辛伐他汀）→ 肌病风险↑

## 联合用药原则
- 推荐组合：ACEI/ARB + CCB、ACEI/ARB + 利尿剂、CCB + 利尿剂、CCB + β 阻滞剂
- 不推荐：ACEI + ARB（增加肾损害与高钾风险）
- 单片复方制剂（SPC）可提高依从性

## 用药宣教
- 长效制剂优先，每日 1 次；固定时间服药
- 血压达标后仍需长期维持，**不可突然停药**（尤其 β 受体阻滞剂，需逐渐减量）
- 定期监测血压、电解质、肾功能；出现干咳、水肿等及时告知医生
