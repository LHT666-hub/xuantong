# 基层常见病常用药物汇总

> 来源：《国家基本药物目录》及基层医疗卫生机构常用药物分类整理

## 心血管系统
| 用途 | 常用药物 |
|------|----------|
| 降压 | 氨氯地平、硝苯地平控释片、缬沙坦、培哚普利、氢氯噻嗪、美托洛尔、比索洛尔 |
| 调脂 | 阿托伐他汀、瑞舒伐他汀、辛伐他汀 |
| 抗血小板/抗凝 | 阿司匹林肠溶片、氯吡格雷、华法林 |
| 心衰 | 呋塞米、螺内酯、地高辛、沙库巴曲缬沙坦 |
| 抗心绞痛 | 硝酸甘油（急救舌下含服）、单硝酸异山梨酯 |

## 内分泌与代谢
- 降糖：二甲双胍、格列美脲、阿卡波糖、达格列净、西格列汀、胰岛素
- 甲状腺：左甲状腺素钠（甲减）、甲巯咪唑（甲亢）
- 抗痛风：秋水仙碱（急性期）、别嘌醇/非布司他（降尿酸）

## 呼吸系统
- 平喘/COPD：沙丁胺醇（气雾剂）、布地奈德、噻托溴铵、氨溴索（祛痰）
- 抗过敏：氯雷他定、西替利嗪

## 消化系统
- 抑酸护胃：奥美拉唑、雷贝拉唑、铝碳酸镁
- 促胃肠动力：多潘立酮、莫沙必利
- 止泻/补液：蒙脱石散、口服补液盐（ORS）
- 通便：乳果糖、开塞露

## 抗感染药物（须凭处方、避免滥用）
- 青霉素类：阿莫西林（用前皮试/询问过敏史）
- 头孢类：头孢呋辛、头孢克肟
- 大环内酯类：阿奇霉素、克拉霉素
- 喹诺酮类：左氧氟沙星（18 岁以下、孕妇慎用）

## 解热镇痛
- 对乙酰氨基酚（注意每日总量、避免叠加含相同成分复方制剂）
- 布洛芬（消化道溃疡、肾功能不全慎用）

## 神经系统
- 卒中二级预防：阿司匹林/氯吡格雷、他汀
- 头晕/眩晕：倍他司汀

## 基层用药安全提示
- 优先选用国家基本药物，遵循适应证用药
- 关注老年人多重用药，定期评估、精简处方
- 抗生素、激素严格掌握指征，避免不合理联用
- 用药前询问过敏史、肝肾功能、合并用药，防范相互作用
- 慢病长期用药者加强依从性教育与随访监测
