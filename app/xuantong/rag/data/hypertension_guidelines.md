# 高血压管理指南摘要

## 诊断标准
- 收缩压 ≥ 140 mmHg 和/或 舒张压 ≥ 90 mmHg
- 非同日三次测量均高于正常值
- 家庭自测血压 ≥ 135/85 mmHg

## 分级
| 级别 | 收缩压 (mmHg) | 舒张压 (mmHg) |
|------|--------------|--------------|
| 正常 | < 120 | < 80 |
| 正常高值 | 120-139 | 80-89 |
| 1级高血压 | 140-159 | 90-99 |
| 2级高血压 | 160-179 | 100-109 |
| 3级高血压 | ≥ 180 | ≥ 110 |

## 治疗目标
- 一般患者：血压控制在 < 140/90 mmHg
- 合并糖尿病/肾病：血压控制在 < 130/80 mmHg
- 老年患者（≥65岁）：收缩压 < 150 mmHg

## 生活方式干预
- 限盐：每日食盐摄入量 < 6g
- 控制体重：BMI < 24
- 规律运动：每周 ≥ 150 分钟中等强度有氧运动
- 戒烟限酒
- 心理平衡

## 常用降压药物
- ACEI（普利类）：依那普利、贝那普利
- ARB（沙坦类）：缬沙坦、氯沙坦
- CCB（地平类）：氨氯地平、硝苯地平
- 利尿剂：氢氯噻嗪、吲达帕胺
- β受体阻滞剂：美托洛尔、比索洛尔

## 注意事项
- 降压治疗需个体化
- 联合用药优于大剂量单药
- 长效制剂优先（每日一次）
- 不可突然停药
- 定期监测血压和靶器官损害
